# Daily Ops

Weekday tracker for routine, planned work, notes, EOD logs and stats — one HTML file, data stays in your browser.

**v3:** installable PWA (iPhone: Safari → Share → Add to Home Screen), week view, day-off marking, clock-aware now marker + EOD nudge, phone↔laptop transfer codes, linked auto-backup file (Chromium), refreshed design.

Files: `index.html` (the whole app) · `sw.js` + `manifest.webmanifest` + icons (offline install support).

Hosting: GitHub Pages → Settings → Pages → main / root.
